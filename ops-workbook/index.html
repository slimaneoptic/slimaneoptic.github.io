7

Import check: a warehouse CSV, staged and checked

  1. ImportThe warehouse CSV is pasted as values into the Import_Staging tab. Nothing else changes.
  2. StagingEvery staged row gets a Result: Ready or Rejected.
  3. ChecksFormulas run the import checks from the Config tab on every row. Rejected rows are listed in the Exceptions tab in plain words.
  4. AppendReady rows appear in Ready_To_Post in ledger column order, with new lots from receipts in Batches order. A person pastes them as values into the next empty rows of Inventory_Ledger and Batches. Existing rows are never edited.

Nothing is overwritten: rejected rows stay out of the ledger and wait in the exceptions report with what to fix, and a movement ID that is already in the ledger is always rejected.

      Portfolio demonstration with invented sample data, not client work. Northfield Nutrition is a fictional brand, and every record on this page is invented.

      Every number on this page comes from one data file (data.js). That file is exported from the workbook after LibreOffice recalculates it, and the export is compared with an independent recomputation from the raw sample records. In your browser the page only counts rows, re-adds the reconciliation and test-case sums, compares dates with the as-of date, sorts and filters.
