How it works

  1. Write the script. Each step is an action (go to a page, click, type, hover) on a CSS selector, plus one caption sentence. A caption can pull live text from the page, like the match count.
  2. Playwright plays it. Headless Chromium at 1280x720 runs the steps, records the screen, and saves a timeline: when each step happened and where each click landed on screen.
  3. Remotion renders the video. It reads the recording and the timeline and adds a title card, a caption for each step, a highlight, click ring and zoom on each target, and an outro. One command, npm run build-video, redoes it all.

The script behind this video

{
  "title": "Stock Screener: screening by ROIC",
  "subtitle": "Find large companies with high returns on capital",
  "url": "https://slimanechanchoul.com/screener-demo/",
  "viewport": {
    "width": 1280,
    "height": 720
  },
  "steps": [
    {
      "action": "goto",
      "waitFor": "#count",
      "hold": 3500,
      "caption": "This screener covers every US-listed stock. You build a screen from conditions."
    },
    {
      "action": "click",
      "selector": "[data-preset=\"roic\"]",
      "hold": 4000,
      "caption": "Start from a preset: ROIC 15%+, revenue up 10%+, market cap above $1B. {{#count}}."
    },
    {
      "action": "type",
      "selector": "#conds .cond:nth-child(1) input",
      "text": "20",
      "hold": 2500,
      "caption": "Raise the first condition: ROIC of at least 20%."
    },
    {
      "action": "click",
      "selector": "#run",
      "hold": 3500,
      "caption": "Click Run screen. Now {{#count}} pass all three conditions."
    },
    {
      "action": "click",
      "selector": "#out th[data-k=\"roic\"]",
      "hold": 4000,
      "caption": "Click the ROIC column to sort: the highest returns on capital come first."
    },
    {
      "action": "hover",
      "selector": "#out tbody tr:first-child td.sym",
      "hold": 4500,
      "caption": "Scroll back to the name: {{#out tbody tr:first-child td.sym}} leads with a ROIC of {{#out tbody tr:first-child td:nth-child(7)}}%."
    }
  ]
}
