How it was built

  1. Collect. One query to the public OpenStreetMap Overpass API for named restaurants, cafes, fast food, hotels, motels, warehouses, wholesale and trade counters, works, industrial features, crafts and anything tagged as selling LPG inside El Paso County, Texas.
  2. Clean. Unnamed features, public utilities (pump stations, ponds, power plants, pipelines) and unrelated shops were dropped. Records with the same normalized name within 150 m were merged as duplicates.
  3. Verify. For up to 30 of the most relevant businesses with a website (one per web domain), the public homepage was read once, with a named user agent, a 10-second timeout and robots.txt respected. Only the words propane, LP gas, LPG and forklift were searched. A dead domain is kept as a data-quality flag.
  4. Score. The rules above. Every row keeps its OpenStreetMap link, so each record can be traced back to its source.
  5. Explain.
  6. Check against customers. Your CSV is matched by normalized name (inside 1 km when your file has coordinates), by house number and street (only where one prospect has that address, so a shared plaza address cannot grey its neighbors), or by location within 75 m. Matches turn grey and leave the export.
