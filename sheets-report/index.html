Cleaning rules

  • Spaces and case: " europe " and "EUROPE" become "Europe" (the most used spelling wins).
  • Duplicates: exact copies are removed (10 in the test). An order ID reused with other values is flagged and the first one kept (2).
  • Dates: text like 2026-09-21 and 21/09/2026 (or 09/21/2026, set in Settings) is read. Cells Sheets already turned into dates are used as they are. Blank, unreadable or future dates are flagged.
  • Amounts: 1,250.00 and 1.250,50 and $1,250.00 are read correctly. Text, zero or negative amounts are flagged.
  • Currencies: €, £, $, Dh and lowercase codes are recognized. Blank or unknown codes are flagged.
  • Missing fields: no order ID, region or product, or a bad quantity: flagged.

Exchange rates

Live from the free Frankfurter API, cached for 6 hours. In the test run: 1 USD = 0.88352 EUR, 1 USD = 0.75461 GBP, 1 USD = 9.7254 MAD (2026-10-02). If the API is down, the last good rates (up to 7 days old) are used and the email says so. With no usable rates the run stops before changing any sheet and emails the error; a simulated outage test checks exactly that.

Install it in your Google Sheet

  1. Put your orders in a tab named Orders: Order ID, Order Date, Customer, Region, Product, Qty, Amount, Currency. Importing a CSV? Untick "Convert text to numbers, dates, and formulas", so Sheets cannot swap day and month.
  2. Extensions > Apps Script: paste the 8 script files and the manifest, then save.
  3. Reports > Run weekly report and allow the permissions. It asks for 5 narrow ones: this spreadsheet only, the menu, the rate API, sending email, and the trigger.
  4. Type your email in the Settings tab the first run creates.
  5. Reports > Install weekly trigger: every Monday between 7 and 8 am, in the sheet's time zone.
