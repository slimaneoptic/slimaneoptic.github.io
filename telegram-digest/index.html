How it works: two paths, one table

The daily path runs from cron at 21:00 Asia/Tbilisi: collect, embed, digest, send. The /ask path runs when a question arrives: embed it, find the nearest stored posts, let Claude answer from those posts only.

2

The run in numbers

Laptop run, 6 October 2026; timings from the scripts' own output.
Sources4 RSS feeds (Hacker News, TechCrunch, The Verge, Ars Technica) and 3 public Telegram channels (t.me/durov, t.me/telegram, t.me/meduzalive in Russian), via the t.me/s preview.
StoragePostgreSQL 16 + pgvector 0.8.7 in Docker. One items table with a UNIQUE sha256 hash (link + title for RSS, post id for Telegram), so re-runs insert only new posts.
Posts stored132 after two collects: 110 items in 2.5 s, then 22 new when t.me/meduzalive was added.
Embeddingsall-MiniLM-L6-v2, 384 dimensions, in a pgvector column: 110 items in 3.8 s, the 22 new ones in 3.2 s.
DigestLast 24 h of posts (125 items, 7 sources) → Claude Haiku 4.5 via OpenRouter → one section per source, one sentence per bullet with its link; 61 s for this seven-section version (an earlier shorter version took 19.8 s). Fallbacks in the code: Claude Sonnet 4.5, Gemini 3.8 Flash.
/askQuestion embedded with the same model → nearest posts by cosine distance (a named source is searched first) → Claude Haiku 4.5 answers in the language of the question, each fact with its post link. Tested in English and Russian.
DeliveryTelegram bot @Slimanedemobot, long polling. Sent as Telegram HTML in chunks of at most 3,800 characters, split on line boundaries so no link is cut.
Schedulecron, 21:00 Asia/Tbilisi daily: collect → embed → digest → send to the saved chat.

Honest limits

What this demo is and is not
  • It runs on a laptop. The bot and the 21:00 refresh work only while the laptop is on; a client version runs on the client's own VPS and accounts.
  • Public Telegram channels only, read through the t.me/s preview. Private groups and chats need a Telethon session on the owner's account; not run here.
  • Only RSS and Telegram sources so far: no email, X, YouTube or newsletters yet.
  • The digest shown is from 6 October 2026, written by Claude Haiku 4.5 via OpenRouter; the sentences are the model's and were not checked against the articles.

All numbers and sentences on this page come from the real run of 6 October 2026 on my laptop. Not indexed by search engines.
