Find your voting districts

Type an address in Vanderburgh County, Indiana. The page finds it on the map, checks which precinct polygon it falls in, and shows that precinct's districts, straight from the county's precinct file.

How it works

  1. The address is turned into map coordinates (geocoding).
  2. A point-in-polygon test finds the precinct that contains it; addresses close to a boundary are flagged, since a geocoded point can be off by a few meters.
  3. The precinct's own data gives the Congressional, State Senate, State House, County Commission, County Council and Township districts.

For a WordPress site, the same lookup ships as a small plugin with a [district_lookup] shortcode. It geocodes on the server with the free US Census geocoder, which also returns official districts to cross-check the precinct file. The KML or GeoJSON is uploaded in the WordPress admin, so new district maps need no code changes.
