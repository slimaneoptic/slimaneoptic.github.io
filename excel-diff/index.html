How it works

  1. Read. SheetJS reads each workbook in the page: every cell's formula and the value Excel saved with it.
  2. Match. Sheets are matched by name and rows by their label in column A, so an inserted or deleted row does not flag the rows below it. Columns are matched by position.
  3. Compare formulas fairly. Before two formulas are compared, the old one's cell references are moved through the row matching. A total that went from SUM(B6:B8) to SUM(B6:B9) because a row was inserted inside it counts as the same formula.
  4. Classify. A hard-coded value that differs is an input change. A formula that differs (or a formula replaced by a typed number) is a formula change. Same formula, different value means something upstream moved.
  5. Trace. From the headline output, the formulas are walked back to list which edits feed it.
The edits made to the sample, so you can check the tool
  1. Inputs: revenue growth 12.0% to 14.0%.
  2. Inputs: WACC (discount rate) 10.0% to 11.0%.
  3. Cash Flow, FY2028 taxes (cell D5): =-D4*Inputs!$B$10 became =-D4*0.25, a tax rate typed into the formula instead of linked to Inputs.
  4. Revenue: a new cost line, "Cloud hosting (new contract)", inserted below Sales and marketing.
  5. Cash Flow: the "Other non-cash items" line deleted.
