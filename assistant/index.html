Returns and refunds

            
Help center article·1 min read

            
You can return any unused item within 14 days of delivery for a full refund. Items must be in their original packaging.

            
Return costs

            
Return shipping is free when the item is faulty or we sent the wrong item. Otherwise a 25 MAD return fee is deducted from your refund.

            
Refunds

            
Refunds go back to your original payment method within 5 working days after we receive the item.

            
Cushion inserts and opened candles can't be returned for hygiene reasons.

            
Start a return

            
To start a return, message us on WhatsApp with your order number.
