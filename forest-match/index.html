Method

  1. Read vegetation type, elevation, slope and aspect on a 30 m grid (UTM).
  2. Take the reference values from a 90 m window at the point.
  3. Keep only cells with the same vegetation type.
  4. Score terrain closeness (elevation ±150 m, slope ±7°, aspect) from 0 to 1.
  5. Keep cells with score ≥ 0.30, drop patches under ~1 ha, turn them into polygons.

Data

  • Vegetation: USGS GAP/LANDFIRE National Terrestrial Ecosystems 2011 (30 m)
  • Elevation: USGS 3DEP seamless DEM, 1 arc-second
  • Both read from Microsoft Planetary Computer (STAC). Outputs: matches.geojson, score.tif (COG).
