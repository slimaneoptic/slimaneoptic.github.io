    Method

    1. Read vegetation type, elevation, slope and aspect on a 30 m grid (UTM).
    2. Take the reference values from a 90 m window at the point.
    3. Keep only cells with the same vegetation type (never water, developed land or no-data cells).
    4. Score terrain closeness from 0 to 1 (scales: elevation 150 m, slope 7°, plus aspect).
    5. Keep cells with score ≥ 0.30, drop patches under ~1 ha, turn them into polygons.
    6. Merge patches closer than 100 m into areas; rank areas by acres × mean score.

    Data

    • Vegetation: LANDFIRE 2025 Existing Vegetation Type (30 m), read from the LANDFIRE image service on its native grid, nearest neighbour (class values kept exact).
    • Elevation: USGS 3DEP seamless DEM, 1 arc-second, read from Microsoft Planetary Computer (STAC).

    Not yet included

    • Satellite-image similarity (the Earth Engine step).
