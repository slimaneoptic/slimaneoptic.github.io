Speak your answer: voice input for existing H5P activities

A real H5P Fill in the Blanks activity with a small add-on: students click the mic, say the word, and H5P checks it the same way it checks a typed answer.

Status: H5P.Blanks 1.14 running in the open-source h5p-standalone player with sample content. Speech uses the browser's Web Speech API (Chrome and Edge). The feedback line is rule-based here; an LLM step is planned. No Moodle in this demo.

The live activity

Click the mic next to a blank and say one word. Typing in the blank still works as normal.

    How it works

    • The H5P content is untouched. Same content.json, same H5P.Blanks library. No rebuild of the activity.
    • An add-on script reads the answers and adds the mic. speech-layer.js loads next to the content, reads the accepted answers from the H5P content, puts a mic button after each blank, and passes the spoken word into the blank so H5P runs its own check.
    • xAPI events go to Moodle as usual. Because H5P does the checking, it sends its normal xAPI statements (interacted, answered with the score). Nothing changes on the Moodle side.
