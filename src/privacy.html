Privacy

This site counts page views to see which pages are read and where visitors come from. It uses no cookies, and the visit log never stores your IP address.

What is logged for each page view

  • The page, its title and the time.
  • The demo settings in the page link (site, color, q, sel, theme), for example the website a demo was opened for, and campaign tags (utm_source, utm_medium, utm_campaign). Anything else in the link is dropped.
  • The website you came from: its name only, not the full address.
  • Country, region and city, looked up from your IP address by the host, Vercel.
  • Time zone and browser language.
  • Screen size, and the kind of device, browser and operating system.
  • A random id for the browser tab, kept in sessionStorage and deleted when you close the tab. It groups the pages of one visit.

What is not logged

  • Your IP address. The API only holds it in memory for the day, to limit abuse.
  • Cookies, or the full browser identification string (user agent).

Your browser keeps only the tab id above and, if you click the theme button, your light or dark choice.

How long it is kept

The last 5,000 page views. Daily totals (views per country and per page) for up to 400 days.

Where it is kept

The site's API runs on Vercel and stores the log in an Upstash Redis database. Only I can read it.

The services that deliver the pages (GitHub Pages, Google Fonts, Vercel, and Streamlit for some demos) see your IP address with each request, under their own privacy policies.

Cloudflare Web Analytics

Page views may also be counted by Cloudflare Web Analytics, which uses no cookies and shows me totals only.

Chat demos

The chat demos (including the WordPress plugin demo) send your question, the page passages and the earlier turns of the chat to this site's API on Vercel, which asks an AI model through OpenRouter. The API keeps questions and answers only in memory, for up to a day, so a repeated question costs nothing.
