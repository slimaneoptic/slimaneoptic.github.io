Dental X-ray alignment prototype: ArUco tube angle, red/green correction, simulated risk

A camera on the X-ray tube sees an ArUco marker fixed on the positioning ring. Each frame gives the angle between the tube axis and the ring in two directions, the distance, a green / amber / red light with the correction in words, and a risk % for image quality. Each reading can be rated Acceptable or Unacceptable and saved.

Status: prototype, not for clinical use; no real X-ray tube or patient image was used. The accuracy numbers come from 48 synthetic views rendered at known angles (0–15°): the Python core read them with a mean angle error of 0.25° (max 1.49°) and a mean distance error of 0.37 mm. The browser camera mode is approximate, because your camera is not calibrated. The risk % is simulated.

1. Try it

Camera mode: print the marker (PDF, 40 mm at 100 % or PNG; ArUco DICT_4X4_50, id 0), hold it flat 20–40 cm from the camera, then tilt it. Nothing leaves your browser.

3. Accuracy on synthetic views at known angles

48 images of the marker were rendered with OpenCV at known poses: tilt 0–15° in random directions, random in-plane rotation, 150–300 mm away, up to 20 mm off-centre, with Gaussian blur (0.5–1.5 px) and noise (2–6 grey levels). Camera: 1280×720, 60° field of view, no lens distortion. Marker: 40 mm on a white card. Each reading was compared with the true pose.

The one colour miss: a view at a true 5.4° read 6.5°, red instead of amber. Near a band edge a 1° error flips the colour, so the delivered version holds the colour until the reading is clearly past the edge. These are ideal-camera numbers; a real lens, light and print add error, which the calibration step keeps down. Raw numbers: accuracy.json.

4. The Python core

The function the delivered app calls on every frame, shortened (the full file also returns the lateral offset and the corners). OpenCV 5, cv2.aruco + solvePnP; K and dist come from the one-time ChArUco calibration.

DETECTOR = cv2.aruco.ArucoDetector(cv2.aruco.getPredefinedDictionary(cv2.aruco.DICT_4X4_50), params)

def simulated_risk(total_deg):          # SIMULATED: logistic curve, 50 % at 6 deg
    return 100.0 / (1.0 + math.exp(-(total_deg - 6.0) / 1.2))

def measure(image, K, dist, marker_mm, marker_id=0):
    gray = image if image.ndim == 2 else cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
    corners, ids, _ = DETECTOR.detectMarkers(gray)
    if ids is None or marker_id not in ids.ravel():
        return None
    c = corners[list(ids.ravel()).index(marker_id)].reshape(4, 2).astype(np.float64)
    h = marker_mm / 2.0                  # IPPE_SQUARE corner order: TL, TR, BR, BL, y up
    obj = np.array([[-h, h, 0], [h, h, 0], [h, -h, 0], [-h, -h, 0]], np.float64)
    _, rvecs, tvecs, errs = cv2.solvePnPGeneric(obj, c, K, dist, flags=cv2.SOLVEPNP_IPPE_SQUARE)
    best = int(np.argmin(np.ravel(errs)))
    R, _ = cv2.Rodrigues(rvecs[best])
    t = tvecs[best].ravel()
    n = -R[:, 2]                         # ring axis in the tube frame; (0, 0, 1) when square-on
    horiz = math.degrees(math.atan2(n[0], n[2]))
    vert = math.degrees(math.atan2(n[1], n[2]))
    total = math.degrees(math.acos(min(1.0, n[2])))
    status = "green" if total <= 3 else "amber" if total <= 6 else "red"
    return {"horizontal_deg": horiz, "vertical_deg": vert, "total_deg": total,
            "distance_mm": float(np.linalg.norm(t)), "status": status,
            "correction": correction(horiz, vert, status),
            "risk_pct_simulated": simulated_risk(total)}

What the delivered version adds

  1. Calibration. The tube camera is calibrated once with a printed ChArUco board, so the angles hold on the real lens.
  2. Zero. One capture with the tube set square to the ring sets the zero, so a camera mounted slightly off the tube axis does not bias the reading.
  3. Desktop app. Python + OpenCV with the live video, the red/green overlay and the correction text, on a USB camera with autofocus off.
  4. Log. Acceptable / Unacceptable per phantom exposure, saved with angles, distance and time in SQLite, with CSV export.
  5. Risk. The simulated curve is replaced by one fitted to those ratings once there are enough of them.

Sample frames and accuracy test made with OpenCV in Python from the marker image; they are synthetic, not photos of a phantom. Marker detection in the browser uses js-aruco2 2.0.0 (MIT), served from this site; see NOTICE.txt.
