Biomedical full-text extraction: a proof of concept on open-access PubMed Central

A list of PMIDs and DOIs goes in. Each one is matched across PubMed, PMC and Crossref, checked for an open licence, and when one exists the full JATS XML is split into sections, tables (CSV), references and supplementary files. Duplicates are merged and every input ID gets a row in the coverage report, with the reason when something is missing.

Run summary

What the pipeline did

  1. ID resolution. PMIDs and DOIs (also https://doi.org/... links, any case) go through the NCBI PMC ID Converter. DOIs that are not in PMC are looked up in PubMed by [doi].
  2. Metadata. Title, journal, year and author count from PubMed (E-utilities efetch), cross-checked against Crossref: title similarity, year (issued, print or online) and journal name. A row passes when all three agree.
  3. Open access and licence. Europe PMC says whether the article is in the PMC Open Access subset; the licence is then read from the article's own XML. For the rest, Unpaywall says whether any legal copy exists and where.
  4. Full text. Open-licence articles only: JATS XML from the PMC OAI-PMH service (Europe PMC as fallback), split into sections with word counts, tables (each to a CSV with its caption), references (with the DOIs and PMIDs found) and supplementary file links.
  5. Dedupe. On normalised DOI first, then PMID. Every merge is logged.
  6. Coverage report. One row per input ID, including the duplicates, with status, licence, counts and the reason for any gap.

Permissions and completeness

How permissions are handled

  • Full text is collected only for articles with an open licence in the PMC Open Access subset (CC BY, CC BY-NC, CC BY-ND and so on), through the official APIs: NCBI E-utilities, the PMC ID Converter, PMC OAI-PMH, Europe PMC REST, Crossref and Unpaywall.
  • The licence is stored per article, read from the article's own XML, so every reuse decision can be traced. On this public page, tables from non-commercial (NC) articles are counted but their CSVs are not republished.
  • Articles that are only free to read (in PMC without a reuse licence, or free on the publisher site) are not bulk-downloaded. The abstract and metadata are kept and the reason is shown.
  • Paywalled articles are marked "not OA". They can be collected only through the client's own institutional TDM licence or publisher API keys (for example Elsevier or Wiley TDM), never by scraping publisher pages or going around a paywall or a block.
  • Polite access: a named tool and contact address on every call, at most 3 requests per second to NCBI, and every response cached so a re-run does not hit the APIs again.

How completeness is verified

  • Every input ID gets exactly one row, duplicates included; the run checks that the row count equals the input count.
  • Every row that is not full text carries a reason: not in PMC, in PMC without a reuse licence, open copy only on a publisher or repository site, or paywalled.
  • Per article: number of main sections and words, tables found and tables with real cell data (tables supplied only as images are counted and flagged), references and how many carry a DOI or PMID, supplementary files.
  • Metadata from PubMed and Crossref must agree on title, year and journal; disagreements are written into the row.
